# V I B E V17.2 — UX / Visual Stabilization

V17.2 — это точечная переработка экранов, которые сильнее всего влияли на ощущение «прототипа»: карточка события, карта, заявки/чаты и сам чат.

## Что изменено

### Экран события
- Обложка теперь полноценная 16:9.
- Категория, район/время и заголовок находятся поверх фотографии на градиенте.
- Метаданные `идут / места / 18+ / цена` собраны в одинаковые компактные бейджи.
- Теги подняты сразу под описание.
- `Поделиться` и `Сохранить` перенесены в компактные кнопки поверх обложки.
- Карточка организатора стала цельной и визуально завершённой.
- Основной CTA оставлен отдельным и не конкурирует со вторичными действиями.

### Карта
- Карта занимает весь доступный экран.
- Сверху плавающая стеклянная строка поиска и горизонтальные фильтры.
- Справа единая колонка `геопозиция / + / −` с touch-target 44×44.
- Убрано дублирование геолокации.
- Bottom Sheet отображается всегда: в Peek показывает количество событий рядом, в Mid/Full — список событий.
- При выборе маркера шторка показывает выбранное событие.
- Атрибуция OSM сохранена.

### Заявки и чаты
- Из шапки убран технический текст про realtime.
- Онлайн-статус оставлен маленькой точкой рядом с заголовком.
- Empty State больше не имеет пунктирной рамки.
- Заявки стали прозрачными строками с разделителями.
- Чаты используют круглые обложки/аватары, время последнего сообщения справа и badge непрочитанных.
- Убраны лишние стрелки и визуальные «кирпичи».

### Чат
- Внутри чата полностью скрыт глобальный Bottom Tab Bar.
- Header показывает конкретное событие, число участников и статус подключения.
- Свои сообщения не показывают ник.
- Подряд идущие сообщения одного автора группируются.
- Аватар входящего автора показывается только у последнего сообщения группы.
- Постоянные `Изменить / Удалить` из bubble убраны.
- Long press / правый клик открывает контекстное меню: ответить, копировать, изменить/удалить своё.
- Добавлен простой reply-preview без изменения схемы Supabase.
- Composer приведён к стандартной компактной форме и больше не конкурирует с навигацией.

## Развёртывание

Если уже установлен V17.1, распакуйте `vibe-minsk-cloudflare-v17-2-patch.zip` поверх репозитория с заменой файлов и сделайте Commit в `main`.

Cloudflare сам выполнит build/deploy.

## Ничего дополнительно настраивать не нужно
- SQL запускать не нужно.
- Supabase Secrets не менять.
- Durable Objects не менять.
- BotFather не менять.
- Telegram chat isolation сохранена: тексты внутренних сообщений не отправляются ботом.
