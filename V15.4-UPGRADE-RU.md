# V I B E V15.4 — Compact Premium UI

Это визуальный density/proportion pass поверх V15.3.2.

## Что меняется

- header ниже и компактнее;
- bottom navigation 62px вместо 68px;
- центральная кнопка создания уменьшена;
- hero/заголовки уменьшены;
- основная карточка события заметно ниже;
- title/body/meta получили отдельную размерную шкалу;
- chips и фильтры компактнее;
- меньше радиусы карточек;
- меньше вертикальные разрывы между секциями;
- detail события уплотнён;
- чат: bubbles и composer компактнее;
- карта: chrome, controls и bottom-sheet компактнее;
- формы, заявки, профиль и уведомления приведены к той же шкале;
- safe-area и отступ под bottom navigation сохранены.

## Что НЕ меняется

- Supabase;
- Telegram auth;
- Cloudflare Worker API;
- realtime / Durable Objects;
- чат;
- заявки;
- карта MapLibre;
- структура базы данных.

SQL и новые Secrets не нужны.

## Установка PATCH

Замените в GitHub:

- `src/styles/tokens.css`
- `src/styles/base.css`
- `src/styles/components.css`
- `src/styles/pages.css`

После Commit Cloudflare автоматически соберёт и задеплоит проект.

После деплоя полностью закройте Telegram Mini App и откройте заново, чтобы исключить старый CSS из WebView cache.
