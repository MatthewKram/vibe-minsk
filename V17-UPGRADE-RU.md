# Обновление V I B E до V17

## Что меняется

V17 реализует продуктовые рекомендации по UX, карте, производительности и безопасности, не меняя существующую схему Supabase.

### UX
- Skeleton-карточки для сетевых загрузок главной, события, заявок, чатов и профиля организатора.
- Анимированные Empty State вместо пустых экранов.
- Bottom-sheet карты имеет три высоты: Peek, Mid и Full. Панель можно тянуть за handle или нажимать на него.
- Единый touch-feedback и Telegram Haptic Feedback.
- Safe Area учитывает Telegram CSS variables и `env(safe-area-inset-*)`.

### Карта
- MapLibre загружается отдельным lazy chunk только при открытии карты.
- GeoJSON кэшируется в памяти; `setData()` вызывается только при изменении координат/категории/числа участников.
- Собственные маркерные пиктограммы рисуются локально, без внешнего sprite CDN.
- Есть кластеры, heatmap, поиск, фильтры и фирменная тёмная тема.
- Кнопка геолокации делает `flyTo` и показывает фактическую точность GPS кругом на карте.
- Bottom-sheet позволяет поделиться событием прямо с карты.

### Медиа
- Карточки используют `<img loading="lazy" decoding="async">` вместо CSS-background там, где это возможно.
- При загрузке обложки приложение уменьшает слишком большие изображения и конвертирует их в WebP, если это уменьшает размер.
- Сервер также принимает AVIF. Media cache-control увеличен до 1 года для уникальных URL.

### Backend
- Публичная неавторизованная лента кешируется через Cloudflare Cache API примерно на 45 секунд.
- Авторизованная лента НЕ кешируется, чтобы не утекли `favorite`, `requestStatus` и `member` другого пользователя.
- После изменений события кеш публичной ленты инвалидируется.
- Wildcard CORS (`*`) удалён: API принимает текущий origin, `APP_URL` и localhost для разработки.
- Авторизованные ответы получают `Cache-Control: no-store`.
- Добавлены security headers (`nosniff`, Referrer-Policy, Permissions-Policy).

### Social
- Избранное хранится в существующей таблице Supabase `favorites` и получило отдельный экран в профиле.
- Поделиться событием можно из detail-экрана и из bottom-sheet карты.
- Внутренний чат остаётся только внутри V I B E; текст сообщений Telegram-ботом не отправляется.

## Как обновить

Если у тебя уже работает V16, проще всего распаковать `vibe-minsk-cloudflare-v17-patch.zip` поверх GitHub-репозитория с сохранением структуры и заменой файлов.

Затем:
1. Commit changes в `main`.
2. Cloudflare Workers Builds автоматически выполнит `npm run build` и `npx wrangler deploy`.
3. SQL запускать не нужно.
4. Secrets менять не нужно.
5. BotFather менять не нужно.

## Что проверить после деплоя

1. Главная сначала показывает skeleton при медленном соединении и корректный Empty State при пустом фильтре.
2. Сердце сохраняет событие; `Профиль → Избранное` показывает его после перезапуска приложения.
3. `Поделиться` открывает системный/Telegram share.
4. На карте работает поиск по району/названию/тегам.
5. Точка геолокации показывает полупрозрачный круг точности.
6. Bottom-sheet карты переключается Peek → Mid → Full и свайпается за handle.
7. Новые сообщения/заявки/realtime-обновления продолжают приходить без reload.
8. Текст сообщений не появляется в Telegram-боте.
