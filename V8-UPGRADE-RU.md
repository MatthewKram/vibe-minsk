# V I B E V8 — обновление

V8 — полный визуальный редизайн поверх рабочего backend V7. Новая SQL-миграция не требуется. Cloudflare Secrets и BotFather менять не нужно.

## Что заменить в GitHub

1. `public/app.js`
2. `public/styles.css`
3. целиком папку `public/assets/covers/`

После Commit Cloudflare автоматически соберёт и задеплоит Worker.

## После deploy

Полностью закрой Telegram Mini App и открой заново, чтобы WebView не держал старый CSS в кеше. При необходимости открой workers.dev URL в браузере с `?v=8`.

## Что изменено

- новая editorial/premium night дизайн-система;
- убран карикатурный synthwave/glow;
- одна акцентная палитра вместо множества неонов;
- собственные локальные арт-обложки для категорий;
- переработаны hero, поиск, категории, подборки и карточки;
- новый bottom navigation;
- унифицированы страницы события, профиля, чата, заявок, карты и форм;
- рабочая серверная логика V7 сохранена.
