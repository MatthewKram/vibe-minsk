# Обновление V I B E V12 → V13

## Главное

V13 полностью убирает Яндекс Карты. `YANDEX_MAPS_API_KEY` больше не нужен. 

## Что заменить в GitHub

Замените файлы:

- `public/index.html`
- `public/app.js`
- `public/styles.css`
- `src/index.js`

После Commit Cloudflare автоматически запустит новый build/deploy.

## Что НЕ нужно делать

- не запускать SQL заново;
- не менять Supabase Secret Key;
- не менять Telegram Bot Token;
- не менять BotFather;
- не создавать ключ карты;
- не менять URL Worker.

Старую переменную `YANDEX_MAPS_API_KEY` в Cloudflare можно удалить, но это необязательно: V13 её больше не читает.

## Проверка после deploy

1. Откройте вкладку «Карта».
2. Должна появиться тёмная карта Минска.
3. Проверьте фильтры «Сейчас», «Сегодня», «Домашние», «Бесплатно».
4. Нажмите на точку события — снизу должна появиться карточка.
5. Нажмите на кластер с числом — карта приблизится.
6. Нажмите кнопку геолокации — если вы в Минске, появится голубая точка пользователя.
7. Нажмите событие в списке ниже — карта сфокусируется на нём.

## Важно про базовую карту

V13 не использует стандартные `tile.openstreetmap.org` напрямую. Карта рендерится MapLibre, а keyless векторный стиль загружается из OpenFreeMap, построенного на данных OpenStreetMap/OpenMapTiles. Для большого коммерческого трафика позже можно без переписывания интерфейса заменить URL стиля на собственный tile-server или отдельного OSM-провайдера.
